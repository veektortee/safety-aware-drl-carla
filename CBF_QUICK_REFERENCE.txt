🚀 FEATURES ADDED

  1. SPEED-DEPENDENT LIE DERIVATIVES
     └─ Throttle/brake effects scale with velocity
     └─ Prevents infeasible constraints at edge speeds
     └─ Formula: effect = base * (speed / v_nominal)

  2. TRUST SCORE MODULATION
     └─ Conservative corrections when ensemble uncertain
     └─ Blends QP result with emergency brake by uncertainty
     └─ Reduces exploration in high-uncertainty regions

  3. STEERING/THROTTLE RATE LIMITING
     └─ max_steering_rate = 0.5 rad/step (configurable)
     └─ max_accel_change = 0.3 per step (configurable)
     └─ Prevents jerky, unrealistic vehicle corrections

  4. DYNAMIC SPEED LIMITS
     └─ Reads speed_limit from cbf_state dict
     └─ Per-road speed enforcement from CARLA waypoints
     └─ Scenario-aware: highways ≠ residential zones

  5. PROACTIVE LANE KEEPING
     └─ Predicts future lane offset using steering model
     └─ Intervenes BEFORE lane crossing (preventive not reactive)
     └─ Uses Ackermann model heuristic: predicted_offset = f(steering)

  6. CONSTRAINT VIOLATION TRACKING
     └─ Counts collisions, lane, speed violations per-constraint
     └─ Exposes metrics via safety_metrics property
     └─ Logs to TensorBoard: safety/collisions, safety/lane_invasions, etc.

  7. REWARD PENALTY FOR CBF CORRECTIONS
     └─ Reward -= correction_penalty * ||u_safe - u_actor||₂
     └─ Default: penalty = 0.01 (tunable)
     └─ Drives agent toward inherently safe behavior

  8. FALLBACK SAFETY VERIFICATION
     └─ If QP solver fails, fallback is constraint-checked
     └─ Maintains previous safe action rather than emergency brake
     └─ Verified against collision/lane/speed barriers

⚠️  CRITICAL FAILURE POINTS

  1. Trust Score Divergence
     Issue: If ensemble Q-values don't diverge, trust_score ≈ 1.0 always
     Check: train/ensemble_uncertainty in TensorBoard
     Fix: Verify K critics differ in their value estimates

  2. Penalty Scale
     Issue: Too high → exploration collapses; too low → ignored
     Tune: Sweep [0.001, 0.01, 0.1], monitor reward curves
     Start: 0.01 (recommended)

  3. QP Solver Failures
     Issue: If >1% failures, constraints may be conflicting
     Debug: Enable verbose in solver.setup(verbose=True)
     Fix: Reduce alpha or loosen d_min/y_max margins

  4. Lane Threshold Over-Conservative
     Issue: y_max=1.5 activates when center still in lane
     Reason: 3.5m lane width, vehicle 1.8m wide
     Tune: Adjust y_max [0.8, 1.2, 1.5, 2.0] per scenario

  5. Speed Limit Staleness
     Issue: Speed limit queried every 30 steps, can be stale
     Monitor: Check cbf_state['speed_limit'] values change
     Solution: Query per-step if dynamic limits vary frequently
